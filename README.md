House Price Prediction
This project predicts the estimated price of a house using a Machine Learning Linear Regression model. The application is built with Streamlit and displays the predicted house price in Indian Rupees.

Project Overview
- Number of bedrooms
- Number of bathrooms
- Living area in square feet
- Lot size in square feet
Working
The user enters the house details in the Streamlit application, and the trained Linear Regression model predicts the estimated price.

Machine Learning Model: Linear Regression

The dataset is divided into:
- 80% Training Data
- 20% Testing Data

The model is trained using the selected house features and house price as the target variable.

Features Used
Bedrooms, number of bedrooms, bathrooms, number of bathrooms, sqft _ living, living area in square feet, sqft _ lot, lot size in square feet, price, House price 

Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Linear Regression

Currency Conversion

The original house prices are in US dollars. The predicted price is converted into Indian Rupees using the conversion rate. The final predicted house price is displayed in Indian Rupees.
